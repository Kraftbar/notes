# chatgpt — December 2022

Answers saved from ChatGPT on 17–18 December 2022, seventeen and eighteen days
after it opened to the public on 30 November 2022. Kept as a period piece: this
is what the model produced in its first few weeks, before GPT-4, before anyone
had worked out how to prompt it.

Each file is stamped with its date and the original prompt, which was also the
filename. Content is otherwise untouched — including the mistakes.

Mostly numerical C: matrix multiply, transpose, SVD (twice), a Kalman filter,
pointer practice, a peer-to-peer WAN sketch.
